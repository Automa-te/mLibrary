# mLibrary
 

## What is mLibrary?
 

*   A simple 1-file python script that manages you media files and archives that contains images.
     
*   Gallery view showing previews of folders/archives containing images and animated snapshots of videos.
     
*   Build in reader for images with pre-set image enhancement.
     
*   Powerful file tagging management with include (,) and exclude (-)
     
*   Zip export to PDF for portable reading.
     

## So what features it have?
 

1.  Gallery view for your files. Comics in archive, folders containing images, stand-alone images and videos.
     
2.  Dual rating system, hearts and stars.
     
3.  Reader feature for archive files and stand-alone images.
     
4.  Image enhancements for reader.
     
5.  Zip export to PDF for reading on the go.
     
6.  File tagging system via categories and sub-categories.
     
7.  Inclusion and exclusion search system.
     
8.  Various item grouping and sorting.
     
9.  1 file only. Just add python and its dependencies.
     

## And what does it not have?
 

1.  No client-server functionality. Offline.
     
2.  No internet access for any data access.
     
3.  No file management.
     
4.  No file modification.
     
5.  No compiled files.
     
6.  No magic.
     

## Is this generated AI code?
 
Yes, in short. I wanted to have a custom library for media management but several options available is either too heavy (in installation and runtime) or too complicated (requires server-client). So a custom solution is made by AI, focusing on the features with minimal overhead for media organisation and handling.
 
\*Note that the code will still be reviewed by human.
 

## Just why?
 
Having a lightweight code that handles most of the used features such as tagging, organisation and reading is enough. Additionally for video files, it generates a animated snapshots without opening the video to know what is the actual video.
 

## What files it generate?
 

1.  library.config > The config file
     
2.  mlibrary.lib > holds thumbnails and SQLite
